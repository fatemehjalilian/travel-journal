# Travel Journal
A responsive travel journal built with React as part of the Scrimba Learn React course.

## About the project
This is my first project with React.

One of the main things I noticed while building it was how much easier React makes it to work with **dynamic data** and **UI**. Instead of controlling individual elements and their changes with JavaScript, I can describe what the UI should look like based on the data and let React handle the rendering.

For example, the travel entries are sorted as data and rendered dynamically using reusable React components. Adding another destination doesn't require creating another section of HTML manually; it can be done by adding another entry to the data.

## Features
- Responsive layout for desktop, tablet and mobile screens
- Reusable React components
- Dynamic rendering of travel entries
- Data-driven UI using JavaScript objects and map()
